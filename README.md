# HAUSWERK Planner

Автономный планнер архитектурного отдела. Работает без ChatGPT и может быть размещён на Node.js-хостинге.

## Что внутри
- Обзор проектов, задач, сроков и прогресса
- Таблица задач
- Kanban-доска
- Проекты и стадии
- Загрузка команды на 4 недели
- Общие данные для всех пользователей через сервер
- Без регистрации и без зависимости от аккаунта ChatGPT

## Хранение данных

В production планнер поддерживает постоянное хранение состояния в S3.

Переменные окружения:

```
S3_BUCKET=<имя бакета>
S3_ENDPOINT=https://s3.twcstorage.ru
S3_REGION=ru-1
AWS_ACCESS_KEY_ID=<access key>
AWS_SECRET_ACCESS_KEY=<secret key>
```

Необязательная переменная:

```
S3_KEY=planner/data.json
```

Если S3 настроен, все проекты, задачи, сотрудники и загрузка команды хранятся в одном приватном JSON-объекте в бакете и переживают redeploy контейнера.

Если S3 не настроен, приложение использует локальный `data.json` — это удобно только для локального запуска.

## Быстрый запуск локально

Нужен Node.js 18+.

```bash
npm install
npm start
```

Открыть:

```
http://localhost:3000
```

## Проверка хранилища

`/api/health` возвращает используемый тип хранилища. В production должно быть:

```json
{"ok":true,"storage":"s3"}
```
