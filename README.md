# HAUSWERK Planner

Автономный планнер архитектурного отдела. Работает без ChatGPT и может быть размещён на любом VPS/Node.js-хостинге.

## Что внутри
- Обзор проектов, задач, сроков и прогресса
- Таблица задач
- Kanban-доска
- Проекты и стадии
- Загрузка команды на 4 недели
- Общие данные для всех пользователей через сервер
- Без регистрации и без зависимости от аккаунта ChatGPT

## Быстрый запуск локально
Нужен Node.js 18+.

```bash
node server.js
```

Открыть:
http://localhost:3000

Внешние npm-пакеты не нужны.

## Размещение на сервере
1. Загрузить папку на VPS.
2. Установить Node.js 18+.
3. Выполнить `node server.js`.
4. Настроить Nginx как reverse proxy на порт 3000.
5. Подключить свой домен, например `planner.hauswerk.ru`.
6. Выпустить бесплатный SSL-сертификат Let's Encrypt.
7. Для постоянной работы запустить через systemd или PM2.

## Важно
Файл `data.json` создаётся автоматически рядом с `server.js` и содержит общие данные команды.
Не удаляйте его при обновлении приложения.

Если хостинг использует эфемерный диск, задайте переменную `DATA_FILE` на путь постоянного диска.
